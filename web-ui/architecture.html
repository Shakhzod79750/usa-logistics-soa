Key Architectural Decisions

SOA over EDA

Core workflows (create shipment, assign driver) need an immediate success/failure answer, so synchronous REST fits better than an event broker at this scale.

Database per service

Each service owns an isolated SQLite database. No service reads another's database directly — every cross-service read goes through a real REST call, like the ones you can watch above.

Stateless JWT verification

Every service verifies JWTs locally with a shared secret instead of calling Auth Service per request — avoiding a central bottleneck, at the cost of instant token revocation.

Fail-fast on downstream failure

If a required service call fails (e.g. Warehouse Service is down), the caller aborts with a clean error rather than writing a partial record.
