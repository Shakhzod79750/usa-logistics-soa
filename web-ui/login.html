SOA Reference Implementation

Four services.
Two languages.
One dispatch console.

This console talks directly to all four backend services from your browser — Auth and Tracking run on Node.js/Express, Shipment and Warehouse run on Python/FastAPI — over a shared REST + JWT contract. Every call is visible live in the Network Trace panel once you're signed in.

Auth Service & Tracking Service — Node.js / Express
Shipment Service & Warehouse Service — Python / FastAPI

First time? Register an Admin account first (needed to create warehouses and manage users), then register a Dispatcher, Driver, and Customer to see role-based access across the console.

Password resets are handled by an Administrator from the Users page — this demo has no email/SMS service to power a self-service "forgot password" flow (see the Context Diagram in the architecture doc, where that's marked as a future integration).
